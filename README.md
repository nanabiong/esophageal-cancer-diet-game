# 食管癌饮食数感游戏

这是一个 HTML5 网页游戏项目的基础结构，当前只包含页面入口、基础样式和开始按钮事件。

## 项目结构

```text
.
├── index.html          # 游戏首页
├── style.css           # 基础居中布局样式
├── game.js             # 开始按钮点击事件
├── data/               # 后续存放游戏数据
├── assets/
│   ├── images/         # 后续存放图片资源
│   └── audio/          # 后续存放音频资源
└── README.md           # 项目说明
```
